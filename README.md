> Generate high-quality blogs instantly with the power of AI

## 🔗 Live Demo
👉 https://intelliblog-ai-blog-generator.onrender.com

---

## ✨ Features
- ⚡ Generate full blogs in seconds
- 🎨 4 Writing Tones — Professional, Casual, Educational, Creative
- 📏 3 Length Options — Short ~300w, Medium ~700w, Long ~1200w
- 🔑 Keyword Integration for SEO-friendly content
- 📋 Copy & Download blog as Markdown file
- 🌐 Beautiful Dark Futuristic UI with Neural Animation

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | HTML, CSS, Vanilla JavaScript |
| Backend | Node.js, Express.js |
| AI Model | LLaMA 3.3 70B |
| Deployment | Render |
